# The Python Cheer-O-Matic

Constructed by Mr Attenborough

Welcome to your first Python challenge of the new academic year. You will make a tiny program that gives its user a personalised cheer. You will practise **output** (`print`), **input** (`input`), and a **loop** (`for`) that repeats instructions.

## Getting started

1. Read the messages in the output window.
2. Complete the tasks below in order. Run your program after every change.

There is more than one correct answer: make your program sound like you!

## Task 1 — Change the message

Find the first `print` instruction. Change its message so the program gives an exciting welcome to a club, team, pet, or favourite game.

For example:

```python
print("Welcome to the Dragon Club!")
```

## Task 2 — Ask the user something

Use `input` to ask the user for their name. Store their answer in the variable called `name`.

Then print a personalised message that includes their name. You can join text together with `+`:

```python
name = input("What is your name? ")
print("Hello " + name + "!")
```

Change the question or message to make it funny or dramatic.

## Task 3 — Repeat the cheer

Ask the user how many cheers they would like. Use a `for` loop so that your personalised cheer prints that many times.

Hint: `input` gives you text, so use `int` to turn the answer into a whole number.

```python
number_of_cheers = int(input("How many cheers? "))

for count in range(number_of_cheers):
    print("Go, " + name + "!")
```

Try entering `1`, then `3`, then `10`. What changes?

## Extensions

- Add a second question, such as their favourite colour, food, or sport, and include the answer in the cheer.
- Inside the loop, print the cheer number too. Hint: `count + 1` starts the numbering at 1.
- Add a final message after the loop, such as `That was brilliant!`.
- Challenge: ask for a score out of 10 and print a different response for scores of 8 or more using `if`.

## Remember

- Text needs quotation marks: `"Hello"`.
- Python cares about indentation. The line inside a loop must begin with four spaces.
- Errors are clues. Read the last line of the error message, fix one thing, and run it again.
