# Vending Machine

*Created by Rose Thorpe*

Dictionaries are used to store data in key:value pairs. In this code, the keys are items in a vending machine and the values are their prices.

### Task 1

Add more snacks to the vending machine.

### Task 2

Ask the user how much money they have instead of always starting with £10.

### Task 3

Make sure that the price of the item is subtracted from the user's funds.

### Task 4

Add the purchased snack to the list of purchased items using the syntax below.

```
my_list.append(my_item)
```
