# Quiz game

_Written by Nachiketh Prabhu_

Can you answer all the questions correctly? Develop a tiny quiz while practising **lists**, **input**, **if/else**, variables, and a **for loop**.

## Getting started

1. Open `c03.py` and run it. Try `Paris`, then run it again and try a wrong answer.
2. Complete the tasks below in order. Run your program after every change.

The starter works, but only asks the first question. These tasks are suitable for beginners who have used `print`, `input`, variables, and `if/else`. Lists and loops are explained below; the shuffle extension is an optional stretch challenge.

`questions` and `answers` are lists. Items have numbered positions called **indexes**, starting at `0`. So `questions[0]` and `answers[0]` are the first question and its answer. `.lower()` converts the player's input to lowercase, so `Paris` and `PARIS` both match `paris`.

## Task 1 — Add more questions

Add at least two questions to `questions`, and add their answers to `answers`.

- Keep the lists in matching order: the second answer must answer the second question.
- Put quotation marks around every answer, including numbers such as `'6'`, because `input` gives you text.
- Use lowercase for stored answers, and separate list items with commas.

For example, you could add `'How many days are in a week?'` and the answer `'7'` at the end of their respective lists.

**Try it:** Run the program to check for typing errors. It will still only ask the first question until Task 4. Count the items in each list: the totals should match.

## Task 2 — Add some messages

Use `print` to add a welcome message before the question and a goodbye message after the answer has been checked. Give your quiz a name or a theme!

**Try it:** Check that the welcome appears first and the goodbye appears after both correct and wrong answers.

## Task 3 — Add a scoring system

Create a variable called `score` with a starting value of `0` before asking the question. Increase it by one inside the correct-answer branch, then display it at the end.

**Hint:** `score = score + 1` adds one to the current score. You can display a number alongside text using `print('Your score:', score)`.

**Try it:** A correct answer should give a score of `1`; a wrong answer should give `0`. For now, there is only one question per run.

## Task 4 — Ask every question

Use a `for` loop to ask all the questions, checking each response against the answer at the same index.

**Hint:** Start your loop with:

```python
for index in range(len(questions)):
```

`len(questions)` counts the questions. `range` produces their indexes: for three questions, these are `0`, `1`, and `2`.

- Replace `questions[0]` with `questions[index]` and `answers[0]` with `answers[index]`.
- Move the input and the whole `if/else` block inside the loop by indenting them four more spaces. The messages and score increase inside the branches need another level of indentation.
- Keep the welcome and `score = 0` before the loop, so the score is not reset for each question.
- Keep the goodbye and final score after the loop, without indentation, so they appear once.
- Show the total possible score too. Hint: use `len(questions)`.

**Try it:** Answer everything correctly, then try a mixture of correct and wrong answers. Check that every question appears once and the final score matches the number you got right.

The starter expects `6` for the insect question and `j.r.r. tolkien` for the author question. Capital letters are accepted, but different punctuation or extra spaces do not match. As a small extra challenge, use `.strip().lower()` to ignore spaces at the start and end of an answer.

## Optional extension — Shuffle the questions

Make the questions appear in a different order each time. This introduces the built-in `random` module and another list.

**Hint:** Add `import random` at the top. Before the question loop, create a list of indexes with `order = list(range(len(questions)))`, then shuffle it with `random.shuffle(order)`. Change the loop header to `for index in order:`.

Shuffle the indexes rather than either of the original lists: using the same index for a question and its answer keeps them paired correctly.

**Try it:** Play several times. Check that every question still appears once and its correct answer is still accepted. A random shuffle can occasionally produce the same order again.
