# Hangman
*Created by Leo Segerstrale*

This week we're making Hangman using the string stuff from Ryan's session. Run the code and have a go first. It mostly works, but a few things are missing and your job is to finish it off.

Have a look at the loop that builds `display`. It goes through the word one letter at a time and adds either the letter or a blank. Also, `in` checks if something is inside a string, so `"n" in "banana"` is True.

## Task 1

Guess the whole word and the game just keeps going. Check if there are any `"_"` left in `display`, and if not, print the word and a winning message, then use `break` to end the loop.

## Task 2

Make an empty string called `wrong` at the top, add each wrong guess onto it, and print it every turn so the player can see which letters they've already got wrong.

## Task 3

Right now you lose a life for guessing the same wrong letter twice, and pressing enter without typing anything counts as a correct guess (try it and see if you can work out why). Fix both so the player just gets told and guesses again. Hint: `continue` skips straight back to the top of the loop.
