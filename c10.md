# Pygame Snake

*Created by Rose Thorpe*

How long will you survive in this classic (but slightly broken) snake game? Run the code to find out....

Then try the tasks bellow to personalise and improve the game.

### Task 1

Change the display width and height to your preference.

### Task 2

Change the background colour to your choice of RGB values (numbers from 0 to 255 representing the strength of red, green and blue in the colour).

### Task 3

The snake currently stays the same length. Add a line of code to fix this.

### Task 4

Currently, there is an issue with the game not ending when the snake touches some of the walls. See if you can use the existing code to determine the next 2 lines to add.

### Task 5

Add a loop so you can have as many food blocks as you would like.

## Extensions

- Make the snake multicoloured by drawing different blocks different colours.

- Randomly add a wall block each time the snake eats a food block. If the snake hits a wall, the game ends.

- Increase the snake's speed a little bit each time it eats a food block.
