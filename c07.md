# Battle Game

*Created by Nachiketh Prabhu*

Can you defeat the monster?

## Overview

This is a simple combat game where you choose an attack from a list to damage a monster.

## Task 1

Currently, the program ends after one attack. Make it so the game ends when the monster's health reaches 0.

Hint: use a `while` loop to check if the monster's health is greater than 0. Make sure the player can choose an attack each turn.

## Task 2

Add some more attacks!

## Task 3: Extension

Give attacks different strengths! Make it so that each attack deals a different amount of damage.

You might want to create a new list to store the damage.
