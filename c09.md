# Battleships
*Created by Leo Segestrale*

Run `c08.py` first and have a go. The computer hides 3 ships on a 5x5 board and you get 15 shots to find them. It works, but a few things are broken.

## The board

In noughts and crosses the board was a 1D list. This time it's a 2D list: a list of 5 rows, where each row is a list of 5 squares. You get a square with `board[row][col]`, so `board[0][0]` is the top left and `board[4][4]` is the bottom right.

```
   0 1 2 3 4   <- col
0  ~ ~ ~ ~ ~
1  ~ ~ ~ ~ ~
2  ~ ~ ~ ~ ~
3  ~ ~ ~ ~ ~
4  ~ ~ ~ ~ ~
^
row
```

Each square holds one of four things: `""` for empty sea, `"S"` for a ship, `"X"` for a hit and `"o"` for a miss. `displayBoard` prints both `""` and `"S"` as `~`, which is how the ships stay hidden.

## The code

- `placeShips` picks random squares and puts an `"S"` on each, skipping any square that already has a ship.
- `fireShot` updates the square you aimed at and returns `"hit"`, `"miss"` or `"invalid"` (off the board). The main loop uses that to decide what to print and whether you lose a shot.
- `isGameOver` is meant to check whether you've won. Right now it always says no.
- `SIZE`, `NUM_SHIPS` and `shots` at the top control the game, so try changing them.

## Tasks

1. The game never tells you how many shots you have left. Print it at the start of each turn using an f-string.

2. Fire at a square you've already hit and see what happens to the board. Fix `fireShot` so that firing at a square that's already a hit or a miss returns `"invalid"`. Look back at how `makeMove` handled this in noughts and crosses.

3. Sink all 3 ships and the game just carries on. Finish `isGameOver` so it returns `True` when there are no `"S"` squares left. You'll need a loop inside a loop, one for the rows and one for the columns.

Tip: winning takes a bit of luck, so to test Task 3 quickly, set `NUM_SHIPS` to 1 or give yourself more shots.

## Extensions

1. Typing a letter instead of a number crashes the game. Stop that happening. `.isdigit()` might help.

2. Let the player type a coordinate like `B3`, where the letter is the row and the number is the column. You'll want to label the rows A to E in `displayBoard` too. `"ABCDE".index("B")` gives you 1.

3. If you lose, show where the ships were. One way is to give `displayBoard` a second parameter that decides whether ships get shown.

4. Make a ship 3 squares long. Pick a random starting square and a random direction (across or down), then check that every square it would cover is on the board and empty before you place it.

5. Give the player their own board with ships on it and let the computer fire back, taking turns. The computer should pick a random square it hasn't fired at yet. First to sink all the other side's ships wins.

6. Make the computer hunt. It fires randomly until it gets a hit, then aims at the squares above, below, left and right of that hit.

5 and 6 are big ones, so save them until you've done the rest.
