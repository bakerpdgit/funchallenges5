# String manipulation

*Created by Ryan Stubbs*

Today we're going to practise working with **strings** in Python.

A string is text, such as `"hello"` or `"python"`.

Remember: **Python starts counting positions from 0!**

For example:

```python
word = "hello"

word[0]  # "h"
word[1]  # "e"
```

# Extension — Slicing

Python can also be used to take a **section** of a string.

Experiment with the code at the bottom of the program:

```python
word[2:4]
word[:3]
word[1:]
word[::2]
word[::-1]
```

Try to work out what each one does.
